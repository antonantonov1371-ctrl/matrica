## Внедрено

| Возможность | Реализация в «Матрице» |
|---|---|
| Быстрый ввод и описание | Существующий редактор сохранён. Подробности открываются через ⓘ или меню задачи. |
| Подзадачи | Чек-лист внутри задачи, отдельные галочки, счётчик выполнения, редактирование и удаление пунктов. Перенос родителя сохраняет весь чек-лист. |
| Папки | Существующие папки Инбокса: создание, переименование, безопасное удаление, перетаскивание и синхронизация порядка. |
| Теги | Поле #тегов, кнопки тегов, поиск по нескольким тегам в строке поиска, массовое добавление. |
| Флажки | Дополнительная отметка и фильтр «С флажком». Приоритет по-прежнему задаётся четырьмя квадрантами. |
| Повторения | Дни, будни, недели, месяцы, годы; интервал и дата окончания. После завершения появляется следующий экземпляр. |
| Короткие месяцы | Повтор 31-го числа попадает на последний день короткого месяца и возвращается к 31-му в следующем подходящем месяце. |
| Уведомления | Существующий сервер и Web Push сохранены; статус устройства и число запланированных напоминаний, предупреждение о прошедшем времени, часовой пояс аккаунта, перенос на 15 минут. |
| Поиск | Название, описание, ссылка, теги, подзадачи и имя папки; поиск по всем датам, независимо от открытого дня. |
| Смарт-фильтры | Сегодня, с датой, с флажком, повторяющиеся, выполненные, все задачи. |
| Массовые действия | Выбор видимых задач, выполнение, восстановление, перенос даты/папки/квадранта, теги, флажки и корзина. |
| Жесты | На сенсорном экране свайп вправо выполняет задачу, влево раскрывает действия; удержание открывает меню. На Mac — правый клик и перетаскивание мышью. |
| Порядок задач | Сортировка по дате, названию, созданию, флажкам; ручное перетаскивание мышью между задачами. |
| Разделы | Четыре квадранта можно свернуть по отдельности. На iPhone одна колонка, на широком экране сетка 2×2. |
| Корзина | Мягкое удаление и восстановление; существующие задачи физически не удаляются. Автоматическая очистка архива отключена. |
| Отмена | Кнопка последнего действия и ⌘/Ctrl+Z вне полей ввода; отмена не затирает более позднюю правку с другого устройства. |
| Копирование | Дублирование, копирование на другую дату и существующие ⌘C/⌘X/⌘V сохранены. |
| Ссылки | Отдельное поле для http/https, открытие в новой вкладке. |

## Границы переноса

Это веб-приложение с Supabase, а не клиент iCloud Reminders. Поэтому Siri, Messages, геозоны в фоне, сканирование документов средствами Apple, системные виджеты, AlarmKit и звонок сквозь беззвучный режим не имитируются. Общие списки с назначением людей потребовали бы отдельной модели доступа; текущие личные задачи не открываются другим пользователям.

Автоматические списки покупок, Apple Intelligence, публикация шаблонов и печать изучены как соседние сценарии, но не добавлены в интерфейс планировщика. Для повторных чек-листов уже доступно дублирование задачи с подзадачами.

На iPhone Web Push подключается из приложения, добавленного на экран «Домой», после явного разрешения. Сервер проверяет время раз в минуту. Успешный ответ службы доставки не доказывает, что iPhone показал баннер; на это влияют разрешения, интернет и Focus. Нативный будильник не заявляется.

## Сохранность и совместимость

- Существующая таблица `tasks`, авторизация и RLS сохранены. Переноса или очистки таблицы нет.
- Новые свойства находятся в прежнем конверте `description` с `matrica:2`. Старые текстовые описания и неизвестные поля метаданных сохраняются.
- При первом чтении после обновления создаётся локальная копия серверных строк отдельно для аккаунта.
- Независимые правки с разных устройств объединяются по полям; чек-листы объединяются по ID пунктов. Одновременная правка одного поля разрешается в пользу локальной несохранённой версии.
- При создании следующего повтора используется стабильный UUID и вставка с `ignoreDuplicates`, чтобы два устройства не создали два одинаковых экземпляра.
- Корзина ставит задаче признак завершения для отмены серверного напоминания и хранит прежний статус для восстановления.
- Старую вкладку перед использованием новых свойств следует обновить на каждом устройстве.

## Проверки

Автоматические тесты находятся в `tests/task-core.test.cjs` и `tests/workflow.test.cjs`. Проверяются старые данные, метаданные, повторы, високосные годы, короткие месяцы, отмена, сохранность при массовом переносе, корзина, поиск, ошибки сети и слияние правок.

Существующие тесты Web Push проверяют валидацию подписок и показ/открытие уведомления в service worker. Транзакционная проверка в Supabase создаёт исключительно временную тестовую запись и заканчивается `ROLLBACK`: постановка напоминания, смена времени, отмена и восстановление. Контрольная сумма всех 63 пользовательских записей до и после проверки совпала.

Браузерные сценарии выполняются на отдельной локальной тестовой странице с искусственными задачами и отключённой отправкой в Supabase. Настоящие пользовательские задачи для таких сценариев не изменяются. Физический iPhone в автоматическую проверку не входит; системный показ push и ощущения от жестов на нём требуют проверки владельцем.
