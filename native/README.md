# Нативная «Матрица»: пробная версия для iPhone и Mac

Отдельный SwiftUI-проект, не оболочка сайта. Веб-версия остаётся доступной по прежнему адресу. Не требуется оплачивать Apple Developer Program для личного запуска через Xcode.

## Первый запуск завтра

1. Установите бесплатный Xcode из Mac App Store: https://apps.apple.com/app/xcode/id497799835. Сегодня загружать его не нужно.
2. Откройте `native/Matrica.xcodeproj`. Сторонние библиотеки и загрузка зависимостей не требуются.
3. Выберите схему **Matrica**, устройство **My Mac**, нажмите ▶. Войдите в существующий аккаунт «Матрицы» (это не Apple Account).
4. Для iPhone подключите телефон к Mac. В Xcode → Settings → Accounts войдите в свой Apple Account. В Signing & Capabilities выберите свою Personal Team и при необходимости уникальный Bundle Identifier. Пароль/код Apple вводите самостоятельно.
5. Выберите iPhone и нажмите ▶. Выполните подсказки Apple о доверии и режиме разработчика на телефоне.
6. В «Матрице» войдите в тот же аккаунт Supabase, дождитесь синхронизации, нажмите колокольчик и разрешите уведомления. Нажмите «Проверить через 5 секунд» и заблокируйте телефон.
7. Создайте тестовую задачу с напоминанием через несколько минут. После синхронизации включите авиарежим и закройте приложение. Проверьте, что напоминание пришло. Измените/завершите задачу и убедитесь, что старое напоминание отменилось. Повторите на Mac. Существующие задачи для проверки удалять не нужно.

Бесплатная подпись iPhone действует 7 дней: затем потребуется повторный запуск из Xcode. Не удаляйте приложение, чтобы обновить подпись. При переустановке/очистке приложения локальные неотправленные правки могут быть потеряны. Перед удалением дождитесь синхронизации. Симулятор не требует Apple Account, но не заменяет проверку уведомлений на телефоне.

## Что входит

- Четыре квадранта, Инбокс, папки, архив с датой завершения, восстановление из корзины.
- Доступные на iPhone и Mac месяцы: боковое меню и кнопка с названием месяца; сворачиваемый календарь в Дне и Неделе.
- Подзадачи, описание, теги, флажки, поиск, повторения с совместимыми с веб-версией идентификаторами.
- Перенос задач между квадрантами, меню действий, копия задачи, быстрые напоминания через 15/30/60 минут; выполнение с задержкой 1,8 секунды.
- Локальная копия каждого аккаунта в Application Support; атомарная запись перед отправкой. Сессия хранится в Связке ключей, пароль не сохраняется приложением.
- Вход и синхронизация через существующий Supabase с пользовательским JWT и действующими RLS. Схема базы не меняется. Серверные задачи никогда не удаляются приложением физически. Неизвестные поля metadata сохраняются.
- Обновление при открытии, возвращении, восстановлении сети и каждые 15 секунд в активном окне. Независимые изменения полей и подзадач объединяются; конфликт одного поля решается в пользу ещё не отправленной локальной правки.
- Системные локальные уведомления через UserNotifications; отдельная платная подписка и APNs для них не нужны. Назначенные уведомления работают без интернета.

## Ограничения первой версии

Это прототип для сравнения с веб-версией. Виджеты, Siri, массовые действия, полное управление папками и все сочетания клавиш веб-версии ещё не перенесены. Системное оформление SwiftUI сохраняет цвет четырёх приоритетов, но не копирует сайт пиксель в пиксель.

Приложение назначает до 60 ближайших напоминаний и пополняет список при открытии/синхронизации. Изменения с другого устройства станут известны после подключения и синхронизации: закрытое приложение не может немедленно отменить старое локальное напоминание по удалённой правке. Фокусирование и системные настройки могут скрыть баннер/звук. Веб-уведомления на том же устройстве могут дублировать нативные — при переходе на приложение их можно отключить отдельно в веб-версии.

Сборка в CI проверяет компиляцию для Mac и iPhone Simulator и модель данных. Проверка на физических iPhone/Mac и реальная доставка уведомлений выполняются после установки Xcode. До неё нельзя считать приложение готовым для ежедневного использования.

## Проверки

`swift test --package-path native/Core`

`xcodebuild -project native/Matrica.xcodeproj -scheme Matrica -destination 'generic/platform=macOS' CODE_SIGNING_ALLOWED=NO build`

`xcodebuild -project native/Matrica.xcodeproj -scheme Matrica -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build`

Тесты проверяют совместимость старых заметок, сохранение неизвестных полей, объединение правок и подзадач, восстановление из корзины, часовой пояс уведомлений и повторения. Векторы идентификаторов получены из действующего веб-модуля task-core.js, включая UTF-16/кириллицу/emoji.

Документация: https://developer.apple.com/documentation/usernotifications/scheduling-a-notification-locally-from-your-app и https://developer.apple.com/help/account/basics/about-your-developer-account.
