# Матрица на iPhone и Mac

«Матрица» устанавливается как веб-приложение без App Store и платы за установку.

1. Откройте https://antonantonov1371-ctrl.github.io/matrica/ в Safari.
2. iPhone: «Поделиться» → «На экран Домой»; оставьте включённым открытие как веб-приложения. Mac: «Файл» → «Добавить в Dock».
3. Откройте установленную «Матрицу», войдите в тот же аккаунт на обоих устройствах и дождитесь синхронизации. Установленное приложение может потребовать отдельного входа.
4. Внизу страницы кнопка «Установить приложение» показывает, сохранён ли интерфейс для запуска без сети.

После первого успешного входа задачи доступны без интернета. Создание, изменение, выполнение, папки, теги и подзадачи сохраняются на этом устройстве сразу. После подключения приложение сначала получает свежие серверные задачи, объединяет независимые изменения, затем отправляет локальные правки. При одновременном изменении одного поля приоритет у ещё не отправленной локальной правки. Для обмена данными между устройствами приложение должно подключиться к интернету; закрытое веб-приложение не гарантирует фоновую синхронизацию.

Первый вход и получение задач с другого устройства требуют интернета. Push-уведомления также требуют подключения; новые напоминания, созданные без сети, попадут на сервер после синхронизации. Это не нативная интеграция с Apple «Напоминания» или iCloud.

Локальная копия разделена по аккаунтам. Выход закрывает доступ к ней до следующего входа, не удаляя неотправленные правки. Очистка данных сайта или удаление приложения может удалить его локальную копию: перед этим дождитесь синхронизации. Запрашивается постоянное хранение, но окончательное решение принимает браузер.

Worker сохраняет только публичные файлы интерфейса. Запросы к Supabase, пароли и ответы API не попадают в Cache Storage. Supabase продолжает проверять сессию и права на каждое серверное действие. Библиотека supabase-js 2.49.8 сохранена локально с лицензией MIT: приложение не зависит от доступности CDN при запуске. Новая версия интерфейса активируется после полного скачивания всех файлов.

Кнопка календаря рядом с уведомлениями и темой сворачивает календарь отдельно в «Дне» и «Неделе». Настройка сохраняется на устройстве. Выбор даты в «Неделе» меняет начало ленты, сохраняя сам раздел.

Проверки: 51 автоматический тест, в том числе перезапуск с локальными правками, объединение правок двух устройств, неудачное подключение, первый вход без сети, выход без удаления очереди, кеш интерфейса без сети, отказ незавершённого обновления и существующие push-сценарии. Интерфейс проверен в браузере при ширине 393 px без горизонтального переполнения. Установку и авиарежим на физическом iPhone нужно дополнительно проверить на устройстве.
