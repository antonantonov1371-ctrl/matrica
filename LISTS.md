# Мои списки и архив месяцев

В левой панели месяцы и пользовательские списки находятся в разделе «Мои списки». Счётчик показывает невыполненные задачи. Существующие папки во «Входящих» представлены теми же списками: копии задач не создаются.

- «Добавить список» создаёт список с названием и цветом. Внутри — четыре квадранта Эйзенхауэра, задачи с датой и без даты. У задач с датой сохраняется привязка к календарю.
- Правая кнопка мыши открывает меню месяца или списка. На телефоне это же меню открывается долгим нажатием; обычная прокрутка отменяет удержание.
- «Убрать в архив» скрывает пункт из панели. Даты, напоминания, подзадачи, завершённость и принадлежность задач не меняются. Задачи остаются доступны в общих разделах и поиске.
- Внизу панели находится «Архив списков». Кнопка «Вернуть» восстанавливает пункт. Это отдельный архив навигации; прежний архив выполненных и удалённых задач работает как раньше.
- Список можно переименовать и изменить его цвет. Задачи можно копировать/вырезать и вставлять в другой список; перенос между его квадрантами не меняет дату задачи.
- На iPhone и в узком окне кнопка с символом списка рядом с уведомлениями открывает ту же панель, включая архив.

## Данные и совместимость

Списки используют существующие folder-записи, а принадлежность задачи — folderId. Цвет и состояние архива записываются в существующий envelope metadata (`navColor`, `navArchivedAt`). Для состояния месяца используется отдельная служебная folder-запись с `navKind: month`, `navMonth: YYYY-MM` и стабильным UUID для одного месяца/аккаунта. Такие записи исключаются из выбора папок и пользовательских списков. Снятие архива сохраняется явным null, чтобы корректно объединяться при синхронизации двух устройств.

В задаче без даты приоритет списка хранится в `inboxQuadrant` (0–3) в том же metadata. Старая nullable колонка quadrant и существующий формат дат не меняются. Обычные задачи без даты и без списка сохраняют прежнее поведение. Неизвестные поля metadata сохраняются.

Новые поля синхронизируются через прежний Supabase и существующие правила доступа. Схема, авторизация и сервер уведомлений не изменены. Архивирование не выполняет SQL DELETE и не завершает задачи. Офлайн-кеш обновлён атомарно вместе с navigation.js. Нативная пробная версия пока не учитывает новые служебные записи; её развитие отложено пользователем.

## Проверки

63 автоматические проверки: прежние функции задач и уведомлений, архивирование месяца без изменения задач, стабильный ID, восстановление после сериализации и объединения правок, архив списка с разными состояниями задач, создание задачи без даты, сохранение квадранта, перенос без изменения даты, копирование/вырезание, защита HTML, открытие меню по правой кнопке, отмена долгого нажатия прокруткой и формирование четырёх квадрантов со своим набором задач.

Живая визуальная проверка в браузере в текущем сеансе не выполнена: управление браузером недоступно, запрос доступа к локальному просмотру был прерван. Это ограничение проверки, а не подтверждение корректной вёрстки на физическом iPhone.
